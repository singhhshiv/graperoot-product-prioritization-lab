# GrapeRoot Product Prioritization Lab

A transparent prioritization exercise for an AI developer-tools startup balancing developer adoption, enterprise demand, engineering capacity, and revenue potential.

The scores are reconstructed for learning; they are not claimed to be the historical scores used by GrapeRoot. The point is to expose assumptions and document overrides, not to let a framework make the product decision.

## How to use it

1. Read the assumptions in [prioritization.csv](prioritization.csv).
2. Recalculate or challenge the scores.
3. Compare them with strategic sequencing and customer evidence.
4. Read the proposed [Now / Next / Later roadmap](roadmap.md).

## PM skills shown

Opportunity framing, quantitative prioritization, uncertainty, capacity trade-offs, roadmap communication, and decision logging.
