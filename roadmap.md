# Proposed Now / Next / Later roadmap

**Now:** reduce setup friction and define the activation and task-quality baseline. Make cost and usage legible enough to support both self-serve learning and enterprise conversations.

**Next:** run a narrow enterprise pilot, validate licensing and deployment requirements, and test context quality on representative cross-file tasks.

**Later:** build scalable enterprise controls and integrations only when demand, willingness to pay, and implementation cost justify them.

## Override log template

For every override of the quantitative ranking, record the evidence, affected segment, dependency, expected downside, decision owner, and review date. A high score is an input to judgment, not a commitment.
